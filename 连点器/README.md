# Clicker Pro（Windows）

Clicker Pro 是一个深色卡片式 Windows 自动连点工具，适合重复点击、固定位置点击、图片识别点击和重复执行鼠标动作。

功能包括：

- 毫秒级点击间隔、点击次数（0 表示无限）、左/右/中键、单击/双击
- 开始前延时、随机间隔、跟随鼠标或固定坐标点击
- F6/F7/F8 全局快捷键，点击输入框后直接按键即可捕获
- 鼠标移动与点击录制、动作表格、回放速度和循环次数
- 图片识别：添加多张 PNG/JPG/BMP/WebP 模板，分别设置匹配阈值和重复冷却；每张图片可配置点击次数、点击间隔、长按/等待，以及可选的后续左/右/中键动作
- 图片识别测试扫描和可见日志；支持多显示器坐标，MSS 截屏失败时自动回退 Pillow
- 图片预览支持自适应缩放、鼠标滚轮、放大/缩小和独立大图窗口
- 图片模板既可以通过文件选择导入，也可以把截图复制到剪贴板后按 `Ctrl+V` 或点击“粘贴图片”直接加入；从资源管理器复制的图片文件也支持粘贴
- 独立的连点、录制、回放和识别状态，停止一个任务不会误伤另一个任务
- 配置、录制和图片识别目标自动保存到 `%LOCALAPPDATA%\ClickerPro`

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

图片识别使用 OpenCV 截屏匹配。第一次使用时，在“图片识别”页面点击“添加图片”，可一次选择多张目标截图；也可以使用系统截图工具复制图片，然后切换回程序按 `Ctrl+V`。选中列表中的图片后，可以在“命中后动作”中设置主动作：点击可重复指定次数，长按可设置持续秒数，也可以勾选“完成后再执行”追加一个点击、长按或等待动作，并为每一步选择左键、右键或中键。编辑区右侧可用“适应”、`＋`、`−` 和“查看大图”检查模板，较小窗口可使用编辑区滚动条。点击“测试一次”只扫描当前屏幕而不会点击，确认结果后再点击“开始识别”。阈值越高越严格，冷却时间用于避免同一目标被连续点击。建议截取紧贴目标边缘的清晰图片，并在目标窗口中运行识别。

## 打包 Windows EXE

双击 `build.bat`，或执行：

```powershell
python -m PyInstaller --clean --noconfirm ClickerPro.spec
```

生成文件位于 `dist\ClickerPro.exe`。详细环境准备见 [BUILD.md](BUILD.md)。
