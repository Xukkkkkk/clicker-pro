# 图片识别基准

运行确定性的合成图片基准：

```powershell
python benchmarks/vision_benchmark.py --include-4k --repeats 5 --output build/benchmark/current.json
```

基准不会截图或发送鼠标输入。它包含原尺寸和缩放目标、目标缺失、多目标、立即点击模式，以及每帧移到远处的目标；检查匹配位置和数量，失败时返回非零退出码。首次发现耗时与缓存热身后的耗时分别报告。`--engine-source` 可以指定旧版 `vision_engine.py`，用于同一台电脑的前后对比。

本次优化在 Windows 10、Python 3.13.13、OpenCV 5.0.0、NumPy 2.4.4 上的测量如下。每项热身 1 次后取 3 次中位数，模板阈值保持不变；首次发现统计发现目标前的全部扫描。基线为 `89b16b1` 中的识别引擎。

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 1080p 原尺寸首次识别 | 85 ms | 6 ms |
| 1080p 每帧移动的目标 | 164 ms | 6 ms |
| 1080p 目标缺失 | 582 ms | 221 ms |
| 4K 每帧移动的目标 | 628 ms | 7 ms |
| 4K 目标缺失 | 2944 ms | 286 ms |
| 4K 立即模式首次发现 1.65 倍目标 | 8236 ms / 8 轮 | 349 ms / 8 轮 |

以上仅为内存截图的匹配耗时，不包含操作系统截图、扫描间隔、鼠标注入、窗口响应和 UI。不同硬件、模板数量、纹理、尺寸与阈值会影响结果。所有这些基准场景的匹配位置和数量检查均通过；这不代表任意游戏画面都能获得相同精度或速度。

优化包括复用灰度/缩小截图、32 MiB 上限的模板缩放缓存、缩小图定位后在原图小区域核验，以及上一位置的实时复核。缓存复核失败后同轮重新搜索；粗搜索阈值只用于提出候选，最终命中仍须通过用户设置的阈值和原始像素颜色/亮度核验。
