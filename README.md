# Clicker Pro（Windows）

Clicker Pro 是一个深色卡片式 Windows 自动连点工具，适合重复点击、固定位置点击、图片识别点击和重复执行鼠标动作。

功能包括：

- 毫秒级点击间隔、点击次数（0 表示无限）、左/右/中键、单击/双击
- 开始前延时、随机间隔、跟随鼠标或固定坐标点击
- 多窗口后台点击：无需激活目标窗口，不移动真实鼠标，不影响同时操作其他软件
- 录制可保存目标窗口客户区坐标，并将移动和点击后台回放到多个窗口
- 图片识别可分别抓取多个非激活窗口，命中后在后台执行点击、长按和后续动作
- F6/F7/F8/F9 全局快捷键（开始/录制/停止全部/暂停继续），点击输入框后直接按键即可捕获
- 鼠标移动与点击录制、动作表格、回放速度和循环次数
- 图片识别：添加多张 PNG/JPG/BMP/WebP 模板，分别设置匹配阈值和重复冷却；每张图片可配置点击次数、点击间隔、长按/等待，以及可选的后续左/右/中键动作
- 图片识别测试扫描和可见日志；支持多显示器坐标，MSS 截屏失败时自动回退 Pillow
- 图片预览支持自适应缩放、鼠标滚轮、放大/缩小和独立大图窗口
- 图片模板既可以通过文件选择导入，也可以把截图复制到剪贴板后按 `Ctrl+V` 或点击“粘贴图片”直接加入；从资源管理器复制的图片文件也支持粘贴
- 独立的连点、录制、回放和识别状态，停止一个任务不会误伤另一个任务
- 配置、录制和图片识别目标自动保存到 `%LOCALAPPDATA%\ClickerPro`
- 连点运行支持暂停/继续（默认 F9）、可调随机间隔范围，以及最长运行时间到点自动停止；F8 仍为停止全部任务。
- 支持导入/导出 `.clickerprofile` 配置档案，包含连点参数、录制动作、图片识别设置和快捷键。
- 图片识别目标可设置每次扫描最多命中数量，适合同时处理屏幕上多个相同按钮。
- 图片识别支持可选灰度匹配，在按钮颜色或主题变化时更稳定。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

后台目标窗口由连点、录制回放和图片识别三个模块共用。在“录制与回放”中启用“后台录制/回放”后，只记录所选窗口内的动作并保存为客户区坐标，回放不会移动真实鼠标。在“图片识别”中启用“后台识别”后，程序会分别抓取所选窗口的客户区，即使窗口未激活或被其他窗口遮挡也可识别并执行动作。

后台模式通过标准 Windows 窗口消息和 `PrintWindow` 工作。最小化窗口、使用独占输入/DirectInput/独占 GPU 渲染或以更高权限运行的游戏和程序可能不会响应，或无法提供有效截图。

图片识别使用 OpenCV 截屏匹配。第一次使用时，在“图片识别”页面点击“添加图片”，可一次选择多张目标截图；也可以使用系统截图工具复制图片，然后切换回程序按 `Ctrl+V`。选中列表中的图片后，可以在“命中后动作”中设置主动作：点击可重复指定次数，长按可设置持续秒数；需要追加点击、长按或等待动作时，再点击“＋”展开后续动作，并为每一步选择左键、右键或中键。编辑区右侧可用“适应”、`＋`、`−` 和“查看大图”检查模板，较小窗口可使用编辑区滚动条。点击“测试一次”只扫描当前屏幕而不会点击，确认结果后再点击“开始识别”。阈值越高越严格，冷却时间用于避免同一目标被连续点击。建议截取紧贴目标边缘的清晰图片，并在目标窗口中运行识别。

提示：图片识别动作编辑器默认只显示主动作，点击“＋”后才会添加后续动作；识别运行时目标预览会隐藏，避免程序识别自身界面。

## 打包 Windows EXE

双击 `build.bat`，或执行：

```powershell
python -m PyInstaller --clean --noconfirm ClickerPro.spec
```

生成文件位于 `dist\ClickerPro.exe`。详细环境准备见 [BUILD.md](BUILD.md)。

`.clickerprofile` 会打包图片模板并可跨电脑导入；`.json` 仍用于兼容旧版配置。
